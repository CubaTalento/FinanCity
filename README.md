# 🏙️ FinanCity

## Videojuego educativo de economía, finanzas y emprendimiento

FinanCity es una experiencia interactiva donde los jugadores aprenden a administrar recursos, crear negocios y tomar decisiones económicas mientras construyen su propia ciudad.

---

# 🎯 Objetivo del proyecto

Crear un videojuego que combine entretenimiento y educación financiera, enseñando conceptos reales mediante una experiencia práctica.

---

# 💡 Concepto

El jugador comienza con recursos limitados y debe:

- Crear oportunidades.
- Administrar dinero.
- Gestionar negocios.
- Tomar decisiones estratégicas.
- Construir crecimiento sostenible.

---

# 🧩 Sistemas principales

- Economía del juego.
- Negocios.
- Progresión del jugador.
- Misiones y desafíos.
- Gestión financiera.
